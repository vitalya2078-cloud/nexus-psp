# KAPSULA — прототип интерфейса

Мультиплатформенная оболочка эмулятора (PSP, PS1, PS2) на чистом HTML/CSS/JS.
Горизонтальная ориентация телефона.

- `index.html` — каркас: вкладки «Игры / Магазин», верхняя панель
- `nexus.css` — стили
- `nexus.js` — экраны, панели поверх, демо-загрузки

Структура: вкладка «Игры» — арт выбранной игры на весь экран и ряд плиток;
«Магазин» — витрина. Карточка игры, поиск, загрузки, уведомления, профиль,
настройки и экранный геймпад открываются панелями поверх.
Данные демонстрационные, обложки рисуются кодом.
