# NEXUS PSP — мобильный веб-интерфейс

Рабочий прототип интерфейса на чистом HTML, CSS и JS (без сборки и зависимостей).
Рассчитан на телефон в горизонтальной ориентации, как приложение.

- `index.html` — разметка
- `styles.css` — стили (дизайн-токены в начале файла)
- `app.js` — логика: экраны, роутинг по `#hash`, симуляция загрузок, настройки

Запуск: открыть `index.html` в браузере или раздать папку любым статическим сервером
(`python3 -m http.server` из папки `docs`). Данные игр — демонстрационные, обложки рисуются кодом.
