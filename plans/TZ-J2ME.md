# ТЗ: Java-игры (J2ME) — «давай начинать» 2026-11-20

## Решения
- Движок: J2ME Loader (github nikita36078/J2ME-Loader, Apache-2.0), закреплённый коммит, патч KAPSULA (`tools/j2me/`),
  скачивается при сборке, как LibretroDroid. Собирается нашими инструментами (AGP 8.7, Java 17, compileSdk 35).
- Без ffmpeg-kit: свой декодер IMA ADPCM (`tools/j2me/Adpcm.java`).
- Без разрешений: камера, микрофон, Bluetooth, геолокация для Java-игр не запрашиваются.
- Отчёты об ошибках оригинала (ACRA → их сервер) не включаются.
- Экран: ВЕРТИКАЛЬНО по умолчанию (макет: игра сверху, клавиатура телефона снизу); игры шире, чем выше, — поворот сам;
  переключатель «Вертикально / Горизонтально» в настройках игры. Горизонтальная раскладка — по второму макету, позже.
- Кнопки — наши, рисует код: софт-клавиши по краям, крестовина с OK, зелёная/красная трубки, 12 цифр (цифра + буквы).
  Нажатие → Canvas.postKeyPressed/postKeyReleased (как их экранная клавиатура).

## Шаги
1. ✅ Модуль `j2me` собирается внутри KAPSULA (AGP 8.7, Java 17, NDK 27.2; зависимости понижены; jitpack только для com.github.*).
2. ✅ (только .jar; .jad — позже) Консоль «Java (J2ME)»: .jar/.jad в библиотеке, проводнике, поиске, папке KAPSULA; установка (jar → dex) при добавлении.
3. ✅ Запуск из KAPSULA (установка при первом запуске) (MicroActivity в процессе :j2me), время в игре, «последний запуск».
4. ⏳ Сейчас — их клавиатура в телефонном виде (тёмные цвета KAPSULA), портрет. Дальше: наша клавиатура телефона вместо их экранной, вертикальный режим, автоповорот.
5. ✅ Картинки: `con-j2me.png` (телефон, свой пиксельный герой вместо похожего на Марио), `ic-jar.png` (карта памяти).
6. Тесты, APK.
