## 1. Тема «Вечер» — четвёртая в «Оформлении» (тёмная / OLED / светлая / вечер)
- Палитра: фон тёплый тёмно-коричневый (~#22170F), карточки ~#3A281C, текст кремовый #F6EAD7, вторичный #C7B396, акцент янтарный #F2A65A.
- Шрифты ТОЛЬКО в «Вечере»: Balsamiq Sans 700 — заголовки, вкладки, кнопки, облачко маскота; M PLUS Rounded 1c (500/700/800) — весь остальной текст. В других темах — как сейчас (Manrope/Rubik). Оба OFL, кириллица; файлы в res/font, тексты лицензий — в «О приложении».
- Главный экран: свет лампы (тёплое пятно сверху слева), лёгкая виньетка, зерно — нарисованы один раз (без анимации, без нагрузки).
- Элементы в «Вечере»: «объёмные» кнопки (тёмная кромка снизу), карточки сильнее скруглены с тёплой обводкой, обложка в светлой рамке с тенью и отражением; карточка «Добавить игру» — янтарный «+» вместо маскота.
- Галочка «Включать вечером сам» (19:00–7:00), по умолчанию выкл.

## 2. Вкладка-переключатель консоли (во всех темах) — заменяет экран «Консоли»
- Вкладка «Игры» показывает выбранную консоль: картинка приставки + `PSP ▾` («Все игры ▾» при всех). На другой вкладке — первое касание открывает игры, второе — список.
- Список — компактный, выпадает под вкладкой (макет `plans/evening/mockup-console-menu.png`): «Все игры», мои консоли (картинка, название, число игр, ⚠ если нужен BIOS и его нет), строка «Ещё N консолей ›» — остальные консоли с тем, что нужно для запуска, и «Добавить игру».
- Долгое нажатие на консоль — BIOS, настройки ядра, время в играх (то, что сейчас на экране консоли).
- Убрать: значок «Консоли» в шапке, плитку «Консоли» в быстрой панели, отдельный экран «Консоли». Раздел BIOS в «Настройках» остаётся.
- Строение главного экрана: ЕЩЁ НЕ ВЫБРАНО — E «Колода» / F «Ретро-меню» / B «Витрина» / C «Карусель» (`plans/evening/layout-*.png`).

## 3. Живой маскот (во всех темах), позы — `plans/mascot/poses-1.png`, `poses-2.png` (24 шт., WebP ~380 px, ~+1 МБ)
- Движение: дыхание, моргание, взгляды по сторонам, плавная смена поз (подскок + растяжка + переход), свечение и искорки; касание — смех и подскок.
- Главный экран: слева над названием игры; приветствие по времени суток один раз за заход (утро — потягивается, день — машет, вечер — кружка, ночь — спит), облачко гаснет через ~5 с.
- Всплывающие сообщения: маскот с реакцией (игра добавлена — коробка, жетоны — монетки, испытание/достижение — кубок, друг — сердце, облако — облачко, ошибка — грусть/испуг).
- Пустые экраны: вместо статичных картинок — живой.
- Настройки → Общие: «Маскот» (вкл/выкл).
