## 4. Проблема пользователя и что сделано (0.45.0)
**Проблема:** часть PSP ISO не находилась автопоиском, а встроенный проводник писал «Это не игра»; через системное окно те же файлы добавлялись и запускались. Файлы лежали в обычной папке памяти с названием «Telegram» (не в Android/media — пользователь уточнил).

**Причина (из кода):** системное окно (`pickGame`) не проверяет содержимое, а проводник и автопоиск фильтруют через `Storage.platformOf → Disc.plausible`. Точную ветку отказа на устройстве не установили; закрыли все варианты (неизвестный размер = 0, ошибка чтения, отсутствие метки CD001, нажатие до окончания проверки).

**Коммит `a36fc12` (0.45.0, versionCode 73):**
- `Disc.kt`: `verdict()` → OK / TEXT / SMALL / NO_MARK; `plausible()` = verdict==OK; неизвестный размер (≤0) больше не причина отказа; `DISC_EXT = iso, cso, zso, chd, pbp`.
- `Storage.kt`: `Check` = Game / Unsure(why) / No(why); `check()` с точной причиной; чтение заголовка SAF через поток или файловый дескриптор; место «KAPSULA» первым в проводнике.
- `Files.kt`: индикатор, пока файл проверяется («Проверяю файл — секунду»); точная причина отказа; сомнительные образы добавляются с пометкой «не проверен»; поиск показывает и такие образы.
- **Папка KAPSULA** (`/storage/emulated/0/KAPSULA`): создаётся при «Доступе ко всем файлам»; игры оттуда появляются сами (до 3 уровней вложенности), уведомление «появилась из папки KAPSULA».
- **Игры без копирования:** файлы телефона из проводника/поиска добавляются «на месте» (`GameLibrary.link`, список в `filesDir/links.json`: путь, консоль, размер). Копирование осталось для системного окна и документов SAF.
- Пропал файл → игра остаётся (`Game.missing`), кнопка «Нет файла» с подсказкой и «Убрать»; повторное добавление того же файла из нового места переносит запись (время в игре сохраняется).
- Удаление: из чужой папки — «Убрать из библиотеки» (файл остаётся); из папки KAPSULA — «Удалить с телефона».
- Знакомство: карточка «Папка KAPSULA»; настройки «Загрузки»: «Папка KAPSULA» (Открыть/Включить) и «Копии игр»; тексты пустых экранов.
- Android 8–10: запрашиваются чтение+запись (WRITE_EXTERNAL_STORAGE maxSdk 29), чтобы создать папку.
- Тесты: `PlausibleTest` (+4), новый `LinkedGamesTest`.
- **Проверено пользователем на телефоне: работает.** Игрокам (latest) НЕ выпущено.

## 6. Supabase (сервер аккаунтов)
- Проект `kapsula`, id `borubfgvjhntepnijxxo`, eu-west-2. 3 игрока, БД 11 МБ, 18 миграций.
- Edge functions: `kapsula` (аккаунт: register, sync, restore, profile, presence, cheer, chest, friends, friend, poll), `kapsula-admin`, `bot`, `img`. Вход — код восстановления `KPS-XXXX-XXXX-XXXX`, на сервере только SHA-256 хэш.
- Таблицы: players, ledger, cos_prices, app_settings, news, admin_log, cheers, friends, inbox, chest_opens. RLS включён без политик — это норма (доступ только через функции с service role). Функции базы закрыты от anon/authenticated — правильно.
- 🔴 **Дыра с жетонами в `kapsula_sync`:** `d_saves` принимается до 1000 за запрос; уровень = (play*2 + saves*30)/1000 + 1; за уровень +100 жетонов без дневного лимита → подделанный запрос ≈ 3000 жетонов, бесконечно. `d_play` тоже накручивается (до минут с прошлого захода + 60 за запрос). Нужно: дневные лимиты на сервере. **Не исправлено.**
- Нет ограничения частоты запросов (register/sync). Нет индексов на admin_log.admin и cheers.from_id (пока неважно).
- `.claude/settings.json` (коммит после `76389fb`): автоматически разрешены 19 инструментов Supabase (чтение + execute_sql, apply_migration, deploy_edge_function). Опасные (pause/restore/delete/reset/create_branch, секреты) — с подтверждением. В текущей сессии файл не подхватился (папки `.claude` не было при старте) — подхватится в новой.

## 7. Обсуждение удержания и фич (режим «рассуждаем»)
- **Главный тезис:** без статистики удержание — догадки → нужна анонимная статистика.
- Отклонено пользователем: карточка «Продолжить» с кадром места выхода (resume уже есть, выигрыш мал).
- Принято в работу (только ТЗ, не начато), этапами с APK после каждого:
  1. Анонимная статистика (через Supabase, отключаемая) + фон под выбранную игру + единые переходы/вибро.
  2. Облачные сохранения — только сейвы игр (КБ), не снимки состояния (20–40 МБ; лимит 1 ГБ бесплатного хранилища). Конфликт → спросить игрока.
  3. Недельные испытания на RetroAchievements + время в игре, награда жетоны (без RA — только цели по времени).
  4. «Позвать в игру» — только одна Wi-Fi сеть (сейчас NetPlay по IP, `Extras.kt`). Игра через интернет — отдельная задача, не включена.
- Не делаем: штрафы за пропуск дней, таймеры «успей», новые сундуки/случайные награды.
- Пользователь обещал накидать ещё идей и проблем. Последнее указание: «Проверь всё, не кодь после проверки».
